  COMMON COMMANDS
  $ npm start .......................... Start server
  $ npm install ........................ Install dependencies
  $ yt-dlp --version .................. Check yt-dlp
  $ PORT=3001 npm start .............. Use different port
  $ pip install -U yt-dlp ............. Update yt-dlp

  BROWSER ACCESS
  http://localhost:3000 ............... Local access
  http://192.168.1.100:3000 .......... Mobile access (replace IP)

  TROUBLESHOOTING
  Port in use? → PORT=3001 npm start
  yt-dlp missing? → pip install yt-dlp
  Module error? → npm install
  Download fails? → pip install -U yt-dlp
